Política de Privacidade

Aplicativo: n8n Gmail 2026

Última atualização: setembro de 2026

1. Finalidade

Este é um aplicativo privado utilizado para integrar contas Google administradas pelo próprio operador a fluxos de automação no n8n.

2. Dados acessados

Dependendo das permissões concedidas pelo titular da conta, o aplicativo pode acessar dados de e-mail necessários para localizar, ler e processar mensagens utilizadas pelas automações configuradas.

3. Uso dos dados

Os dados são utilizados exclusivamente para executar as funções de automação autorizadas pelo titular da conta. Os dados do Google não são vendidos nem utilizados para publicidade.

4. Compartilhamento

O aplicativo não comercializa dados pessoais. O processamento pode ocorrer na infraestrutura técnica usada para executar o n8n e os serviços necessários ao funcionamento das automações.

5. Segurança

O acesso depende de autorização da conta Google e das credenciais configuradas pelo operador. O operador é responsável por restringir o acesso à sua infraestrutura de automação.

6. Revogação

O titular pode revogar o acesso concedido ao aplicativo a qualquer momento pelas configurações de segurança da própria Conta Google.
